⚙️ Control Flow (Conditionals & Loops)

If-else ladder

int marks;
cout << "Enter marks: ";
cin >> marks;
if(marks >= 90)
    cout << "Grade A";
else if(marks >= 75)
    cout << "Grade B";
else
    cout << "Needs improvement";

For Loop - print squares

for(int i = 1; i <= 5; i++) {
    cout << i*i << " ";
}
// Output: 1 4 9 16 25

While loop (sum of digits)

int n = 257, sum = 0;
while(n > 0) {
    sum += n % 10;
    n /= 10;
}
cout << "Sum of digits: " << sum; // 14

🔧 Functions in C++

Functions help you reuse code and keep programs modular.

Function example: addition

#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(12, 8);
    cout << "Sum = " << result; // 20
    return 0;
}

Function Overloading

double add(double a, double b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }

Pass by Reference (swap)

void swapNums(int &x, int &y) {
    int temp = x;
    x = y;
    y = temp;
}
⭐ References allow modifying original variables efficiently.

🧩 Object-Oriented Programming

C++ supports classes, inheritance, polymorphism — the heart of OOP.

Class & Object (Car example)

#include <iostream>
#include <string>
using namespace std;

class Car {
private:
    string brand;
    int year;
public:
    Car(string b, int y) : brand(b), year(y) {}
    void showInfo() {
        cout << brand << " (" << year << ")" << endl;
    }
};

int main() {
    Car myCar("Toyota", 2003);
    myCar.showInfo();
    return 0;
}

Inheritance example

class Animal {
protected:
    string name;
public:
    Animal(string n) : name(n) {}
    void speak() { cout << "Animal sound"; }
};

class Dog : public Animal {
public:
    Dog(string n) : Animal(n) {}
    void speak() { cout << name << " barks! Woof!"; }
};

Polymorphism achieved via virtual functions. OOP helps in large-scale software design.

💡 Sample Challenge: Prime Check

bool isPrime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

Implement main to test prime numbers. Happy coding!
